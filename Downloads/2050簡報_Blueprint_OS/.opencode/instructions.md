# OpenCode Instructions for Antigravity Synergy

## 🤝 Agent Workflows & Collaboration Rules
1. **架構與設計導向**：本專案的主要架構規劃、UI/UX 美學設計與系統規格由 Antigravity 統籌。
2. **任務導向執行**：請優先參考 `.antigravity/tasks/` 目錄下的 Markdown 檔案進行程式碼開發、除錯與型態修復。
3. **單元測試與修復**：收到 Antigravity 傳送的終端指令時，請專注於精確的代碼修改與單元測試驗證。
4. **狀態回饋**：完成任務後，請更新該任務檔中的待辦事項為 `[DONE]`，並記錄簡易修復摘要。
