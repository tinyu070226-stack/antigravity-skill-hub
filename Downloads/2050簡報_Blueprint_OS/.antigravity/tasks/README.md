# Antigravity × OpenCode Task Board

本目錄用於存放由 Antigravity 拆解的架構需求與待辦清單，供 OpenCode 自動讀取與執行。

## 📋 任務標準模板 (Task Template)

```markdown
# Task-XXX: [任務名稱]

## 🎯 需求說明
[描述具體需求與系統架構細節]

## 📝 待辦事項 (Checklist for OpenCode)
- [ ] 實作 / 修改 [檔案路徑]
- [ ] 執行型態檢查與單元測試

## 📌 修改記錄 (Modification Log)
- (待完成後由 OpenCode 填寫)
```
